フォントは、このアプリで使う文字だけを残したサブセットです（`dev/fonts/make_fonts.py`）。
作り直したフォントであることを示すため、内部の名前は TM Display / TM Gothic / TM Mono に変えています
（IBM Plex Mono の予約フォント名「Plex」を使わないため）。著作権表示とライセンスの欄は元のままです。
